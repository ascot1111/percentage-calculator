# Percently — Percentage Calculator

A styled, mobile-friendly percentage calculator that works well on an iPad.

## Use it as an iPad shortcut

1. Open the deployed website in **Safari**.
2. Tap **Share**.
3. Choose **Add to Home Screen**.
4. Tap **Add**. It will open like an app, and the calculator can work offline after its first visit.

## Calculation

The app calculates:

`percentage of number = number × percentage ÷ 100`

For example, `12% of 100 = 12`.
